# Security

Do not post secrets, infrastructure addresses, private dumps or sensitive exploit details in public issues or PRs. Use a private reporting route supplied by the repository owner when available.

Secret scanners and the allowlist detect known patterns, not every possible secret. A leaked credential must be revoked/rotated; removing a file does not retract existing copies.

This package does not provide deploy workflows or self-hosted runner access. Keep production configuration and operational evidence outside this public repository.
